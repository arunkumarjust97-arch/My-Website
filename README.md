## 🚀 Getting Started

### Prerequisites
- **Node.js** (v18.0.0 or higher recommended, verified on v24.19.0)
- Any modern web browser (Chrome, Edge, Firefox, Safari)

### Installation & Launch

1. **Clone the repository:**
   ```bash
   git clone https://github.com/arunkumarjust97-arch/Super-Blocker-WebSite.git
   cd Super-Blocker-WebSite
   ```

2. **Start the local server:**
   ```bash
   npm start
   # or
   npm run dev
   # or
   node server.js
   ```

3. **Open the live application:**
   Navigate to **[http://localhost:5173/](http://localhost:5173/)** in your browser.

## 🧪 Automated Quality Assurance (QA) Suite

The project includes an enterprise-grade automated audit verifying **106 tests across 7 quality dimensions**:

```bash
# Run the deep audit test suite
npm test
# or
node deep_audit.js

# Run the lightweight audit
npm run audit
```

On Windows, convenient batch/powershell runners are also available:
```cmd
qa.bat
```

### Audit Dimensions Verified:
1. **File System Integrity & Assets:** Verifies all HTML, CSS, JS, PDF, and image assets exist and are non-empty.
2. **HTML Structure & Syntactic Symmetry:** Validates closing tags, 51 unique IDs, and anchor links.
3. **Web Accessibility (WCAG 2.1 AA) & Security:** Confirms alt tags, button labels, form associations, and `rel="noopener noreferrer"`.
4. **SEO Metadata & Structured Data:** Validates OpenGraph cards, Twitter cards, robots.txt, sitemap.xml, and schema.org JSON-LD graph.
5. **CSS Design System & Variables:** Checks syntax balance (530+ rules, 825+ parentheses), media queries, and all 37 custom properties.
6. **JavaScript Runtime Simulation:** Bytecode compilation, state machine evaluation, tab switching, and modal lifecycles.
7. **Live Dev Server Endpoints:** HTTP 200 checks, correct MIME headers, cache control, and 403 path traversal defense.
